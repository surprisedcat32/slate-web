# Slate Linux

Slate Linux is a minimal, DIY Linux distribution built around musl, a custom package manager, shell-based initialization, and a ports system.

Slate is designed to provide a small, usable base system without forcing a predefined desktop environment or unnecessary dependencies.

## Features

- musl-based userspace
- Custom Slate package manager
- Ports-based software management
- Multiple package repositories
- Custom shell-based init system
- Toybox-based initramfs
- X11 support
- Minimal default installation
- Configurable parallel builds
